# Kleexck Game

A simple browser-based game built with Angular. Move a red square using arrow keys or WASD.

## Development

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
ng serve
```

3. Build for production:
```bash
ng build
```

## Deployment

The project uses FTP for deployment. Deployment scripts are in the `scripts` directory.

To deploy:
```bash
node scripts/deploy.js
```

Note: Requires proper FTP credentials to be configured.
